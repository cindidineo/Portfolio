# JSON Website

This folder contains a small static JSON file and an index.html that displays it.

Files added:

- `json-website/issues.json` — sample data extracted from your test messages.
- `json-website/index.html` — static viewer that fetches and shows the JSON.

To publish as a static site using GitHub Pages:
1. Go to your repository Settings → Pages.
2. Set the source to the `main` branch and root (or `/json-website` if you prefer) and save.
3. The site will be available at `https://<your-username>.github.io/Portfolio/` (or with the folder path appended).
