What this page contains

This page displays the Python script used in the repository to build a Retrieval-Augmented Generation (RAG) "Chat with my CV" demo. The script uses LangChain, FAISS, and OpenAI embeddings. It includes demo questions and an interactive loop.

Python script (RAG Chat Demo)

You can copy this code and save it as a .py file to run locally. Make sure you have a PDF named /mnt/data/CV.pdf and your OPENAI_API_KEY set in a .env file.

from langchain.document_loaders import PyPDFLoader
from langchain.vectorstores import FAISS
from langchain.embeddings import OpenAIEmbeddings
from langchain.chat_models import ChatOpenAI
from langchain.chains import RetrievalQA

loader = PyPDFLoader("/mnt/data/CV.pdf")
docs = loader.load()
db = FAISS.from_documents(docs, OpenAIEmbeddings())
qa = RetrievalQA.from_chain_type(ChatOpenAI(), retriever=db.as_retriever())
print(qa.run("What are my top 3 technical skills?"))
Just built a "Chat with my CV" using RAG 🚀

Instead of relying on generic LLM answers, I grounded an AI on my own resume using Retrieval-Augmented Generation. 
This let me ask specific questions and get factual answers pulled directly from my document.
# 1. Install requirements first
# pip install langchain langchain-community langchain-openai faiss-cpu pypdf tiktoken python-dotenv

import os
from dotenv import load_dotenv
from langchain_community.document_loaders import PyPDFLoader
from langchain_community.vectorstores import FAISS
from langchain_openai import OpenAIEmbeddings, ChatOpenAI
from langchain.chains import RetrievalQA
from langchain.text_splitter import RecursiveCharacterTextSplitter

# 2. Load your OpenAI API Key
load_dotenv()
# Make sure you have OPENAI_API_KEY in a.env file
# OPENAI_API_KEY=sk-...

PDF_PATH = "/mnt/data/CV.pdf"

print("1. Loading your CV...")
# 3. Load PDF
loader = PyPDFLoader(PDF_PATH)
documents = loader.load()

print("2. Chunking document...")
# 4. Split into chunks so embeddings work better
text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=1000,
    chunk_overlap=200
)
docs = text_splitter.split_documents(documents)

print("3. Creating embeddings + Vector Store...")
# 5. Create embeddings and store in FAISS
embeddings = OpenAIEmbeddings()
vectorstore = FAISS.from_documents(docs, embeddings)

# Save it so you don't re-embed every time
# vectorstore.save_local("cv_faiss_index")

print("4. Setting up RAG QA Chain...")
# 6. Create the RAG chain
llm = ChatOpenAI(model="gpt-4o-mini", temperature=0) # cheap + good

qa_chain = RetrievalQA.from_chain_type(
    llm=llm,
    chain_type="stuff",
    retriever=vectorstore.as_retriever(search_kwargs={"k": 3}),
    return_source_documents=True
)

print(" RAG is ready! Ask questions about your CV\n")

# 7. Ask the 5 demo questions
questions = [
    "What are my top 5 technical skills and tools listed on my CV?",
    "Summarize my most recent project experience and what tech I used.",
    "What certifications or education do I have according to the CV?",
    "Based on my CV, what kind of web development internship roles am I qualified for?",
    "What is my contact info and LinkedIn/GitHub if listed?"
]

for q in questions:
    print(f"\n--- Q: {q} ---")
    result = qa_chain.invoke({"query": q})
    print(f"A: {result['result']}")
    print("Source:", result['source_documents'][0].page_content[:200], "...")

# 8. Interactive chat loop
while True:
    user_q = input("\nAsk anything about your CV [or type 'exit']: ")
    if user_q.lower() == 'exit':
        break
    result = qa_chain.invoke({"query": user_q})
    print("Answer:", result['result'])

    llm=llm,

embeddings = OpenAIEmbeddings()

# 5. RAG Chain with anti-hallucination prompt
prompt_template = """
You are answering questions about Dineo Cindi based ONLY on her CV provided below.

)

How to use

  1. Install the Python dependencies listed in the script comments.
  2. Place your CV at /mnt/data/CV.pdf or update PDF_PATH to point to your file.
  3. Create a .env file containing OPENAI_API_KEY=sk-....
  4. Run the script with python3 rag_demo.py (or your chosen filename).
